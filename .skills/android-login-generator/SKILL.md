# Android Login Screen Generator

## Purpose

Generate a fully functional login screen using Jetpack Compose.

## When to Use

- When user asks for login/signup UI
- When authentication UI is needed

## Steps

1. Create a composable function named LoginScreen
2. Add:
    - Email TextField
    - Password TextField
    - Login Button
3. Use Column layout
4. Add padding (16dp)
5. Add basic validation (non-empty fields)

## Rules

- Use Jetpack Compose only
- Use Material3 components
- Keep UI responsive
- No XML

## Output

- Return complete Kotlin file
- No explanation

## Optional Enhancements

- Add ViewModel if user asks
- Add API call if requested
